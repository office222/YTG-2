Create the first working prototype of a SaaS platform with the temporary project name FACELESS.

FACELESS helps people research, create, publish, monitor, and improve faceless YouTube channels using AI.

For this first build, create only the application shell and onboarding experience. Do not build AI generation, YouTube integrations, subscriptions, payments, or automation yet.

Create:

A professional landing page with the headline: “You Decide Where You’re Going. Your AI Army Does the Work.”

Supporting text: “Research. Create. Publish. Monitor. Optimize. Generate.”

A primary call-to-action button: “Build My Channel.”

A simple sign-up and login interface.

After sign-in, show an onboarding screen with three prominent choices:

Choose a Niche

Find a Niche for Me

Check My Niche

Create a basic dashboard shell with navigation for:

Dashboard

Niche Research

Competitor Watch

Video Studio

Channel Guardian

Analytics

Credits & Plan

Settings

Use a modern, trustworthy SaaS design with a dark navy background, white text, electric-blue accents, and restrained gold highlights. Make it polished but easy to understand for users who are not technically experienced.

Use text and simple interface icons only. Do not generate custom images or videos. Make all pages responsive for desktop and mobile.

Before finishing, verify that navigation works and that all three onboarding choices lead to clearly labeled placeholder screens. Do not implement anything beyond this defined scope.
